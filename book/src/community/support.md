## Question or bug?

Use Discussions for “how do I…” or “is this supposed to…”. Use Issues when you
can show something is broken.

## Making questions answerable

Include:

- Churust version and enabled features  
- `rustc --version`  
- Smallest code that shows the problem  
- Expected vs actual behavior  
- Full error text  

## Response times

Maintained in spare time. Expect a few days; security reports follow
[SECURITY.md](https://github.com/davthecoder/Churust/blob/main/SECURITY.md).
